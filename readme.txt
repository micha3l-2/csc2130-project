 Project Title

School Management System

 Purpose

The School Management System is a web-based information management application designed to help schools manage student, teacher and administrative records efficiently. It will reduce manual paperwork, improve access to information and make school record management easier and more organized.

 Target Users

* School administrators
* Teachers
* Students
* Parents/Guardians
* School management

 Main Features

1. Student registration and management
2. Teacher management
3. Class and subject management
4. Attendance management
5. Examination and results management
6. Fee management
7. User login and authentication
8. Reports generation

 Why I Chose This Project

I chose this project because schools handle a large amount of information that needs to be stored, updated and accessed regularly. A web-based system can help reduce paperwork, improve record organization and make information easier to access. The project will also allow me to apply web development concepts such as HTML, CSS, JavaScript, PHP and MySQL in solving a real-life problem.



 1. Difference between a Static Website and a Dynamic Web Application

A static website displays fixed content that usually remains the same for all users unless the developer manually changes the files. A dynamic web application can generate and update content based on user input, databases, authentication and other conditions. Dynamic applications commonly use technologies such as PHP and MySQL.

 2. Why do we use localhost instead of a domain name during development?

We use localhost because it allows developers to run and test a website on their own computer without publishing it on the internet. It makes development faster, safer and easier before the application is deployed to a live server.

 3. What is the purpose of the htdocs folder in XAMPP?

The htdocs folder is the main directory where website project files are stored in XAMPP. Apache uses this directory to serve web pages through localhost. For example, a project stored in `C:\xampp\htdocs\csc2130-project` can be accessed using `http://localhost/csc2130-project/`.

 4. Why is it important to organise your project into folders?

Organising a project into folders makes the files easier to find, manage and maintain. For example, CSS files can be stored in the `css` folder, JavaScript files in `js`, images in `images`, and reusable PHP files in `includes`. Good organisation also makes collaboration and future development easier.
